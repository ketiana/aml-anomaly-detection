# Unsupervised Transaction Anomaly Detection for AML

A machine learning project that flags suspicious financial transactions without using labeled data. It learns what "normal" transaction behavior looks like, ranks each transaction by how unusual it is, and turns the result into an investigation priority queue a compliance team could act on.

📊 [View Full Project Writeup](https://ketiana-portfolio.netlify.app/projects/aml-anomaly-detection/)

---

## Dataset

The [IBM Transactions for Anti Money Laundering (AML)](https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml) — a synthetic dataset of ~5 million transactions generated by IBM Research. This project uses the HI-Small file. Download it from Kaggle and place `HI-Small_Trans.csv` in your `data/` folder before running the notebook.

---

## Reproduction Steps

1. Clone this repository
2. Download the AML dataset from Kaggle (link above) and place `HI-Small_Trans.csv` in the `data/` folder
3. Open `aml_anomaly_detection.ipynb` in Google Colab
4. Run all cells top to bottom

> **Environment:** Google Colab with Python 3.10+.

---

## Technologies Used

- **Python 3.10+**
- **PyTorch** — autoencoder (the strongest-performing detection method)
- **scikit-learn** — Isolation Forest, preprocessing, metrics
- **PyOD** — ECOD anomaly detector
- **pandas / NumPy** — data manipulation
- **matplotlib** — visualizations
